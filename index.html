关于本仓库

  • 这里是导航门户：本仓库只放这一个入口页和一份 README.md，不包含三款游戏的源码。
  • 两款单文件游戏按相对路径引用，需要把 kaiyuanmaoxiandao/、paoku/ 放在与本页同级的位置才能直接打开。
  • TenDispatch 由独立仓库维护，需要 Node.js 20.19+ 或 22.12+，在其目录内 npm install && npm run dev。
